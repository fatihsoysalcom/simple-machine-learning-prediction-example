# Simple Machine Learning Prediction Example

This example demonstrates the fundamental concept of machine learning: learning from data to make predictions. It generates synthetic customer data, trains a simple Logistic Regression model to predict product purchases based on age and income, and then uses the trained model to predict for new, unseen customers. This illustrates how computers can learn patterns without explicit programming.

## Language

`python`

## How to Run

1. Ensure you have Python installed (Python 3.6+ recommended).
2. Install the necessary libraries: `pip install scikit-learn numpy`
3. Run the script from your terminal: `python main.py`
